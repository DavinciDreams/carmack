# 📚 Carmack Coder Documentation System

## Overview

The Carmack Coder Documentation System is a comprehensive, automated solution that keeps your documentation in perfect sync with your codebase changes. True to the Carmack philosophy, it eliminates manual documentation maintenance through intelligent automation.

## ✨ Key Features

### 🔍 **Intelligent Code Analysis**
- **Function Extraction**: Automatically discovers and documents all exported functions with JSDoc comments
- **Class Documentation**: Catalogs classes, interfaces, and types with full context
- **Pattern Recognition**: Extracts transformation patterns from JSON configuration files
- **Configuration Mapping**: Documents configuration schemas and options

### 🔄 **Real-time Auto-Updates**
- **File Watching**: Monitors source code changes using chokidar
- **Instant Regeneration**: Updates documentation within milliseconds of code changes
- **Debounced Updates**: Intelligently batches multiple changes to prevent spam
- **Zero Manual Intervention**: Documentation stays current without developer effort

## 🚀 Usage

### Basic Documentation Generation
```bash
# Generate documentation once
bun run docs

# Use the CLI directly
bun run docs:cli
```

### Watch Mode (Automatic Updates)
```bash
# Start watch mode for automatic updates
bun run docs:watch

# With custom directories
bun docs-cli.ts --watch --source-dir ./packages --output-dir ./documentation
```

### CLI Options
```bash
# Full CLI help
bun docs-cli.ts --help

# Custom source and output
bun docs-cli.ts --source-dir ./src --output-dir ./generated-docs

# Multiple formats
bun docs-cli.ts --formats markdown --formats json
```
